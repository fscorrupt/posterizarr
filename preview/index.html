Manage Your Artwork From the Web UI

Posterizarr creates and manages artwork for Plex, Jellyfin, and Emby, with experimental support for Silo. Silo does not yet have full feature parity with the other servers. Use the dashboard to check engine status, upcoming schedules, and recently generated artwork. Open Action Center to review assets that need attention, or Insights to explore execution history and runtime statistics.

  • Install Posterizarr for a new setup.
  • Review assets in Action Center to resolve artwork issues.
  • Create reusable Blueprints for asset-generation recipes.
  • Configure automation for scheduled and externally triggered runs.

Native Dynamic Overlays

Builders > Dynamic Overlays previews and composites supported badges for posters, titlecards, and backgrounds. Choose a library and format, adjust badge placement, check required assets, and sync directly to Plex, Jellyfin, or Emby. Clean source artwork stays unchanged on disk.

Start with Dry Run to evaluate and render changes without uploading artwork. Supported Kometa-style YAML can be imported, but Posterizarr does not run Kometa and does not implement every Kometa feature.

Open the Dynamic Overlays setup guide

Import IMDb Ratings Locally

Posterizarr can import IMDb's official ratings, episode, and title datasets into a local index. Missing IMDb scores can then be resolved locally, without an API call for each successful lookup. Episode matching and manual episode/season mapping help with alternate numbering and anime.

Open Builders > Dynamic Overlays > Sync & Cache > Browse Ratings for Local IMDb Dataset and Download & Update. The download and indexing require disk space and time; IMDb's datasets are for non-commercial use only.

Read the IMDb import and matching guide.

Explore Run History

Insights brings run counts, success/error filters, durations, artwork totals, storage figures, and interactive charts into one view. Its optional Demo mode lets you explore the interface using simulated runs.
