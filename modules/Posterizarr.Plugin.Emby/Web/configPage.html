Plex Direct Sync

Mirror artwork (including Kometa overlays) directly from Plex to Emby. Can be used alongside Real-Time Sync.
💡 Combining Real-Time Sync & Plex Direct Sync
You can use both features together:
  • Real-Time Sync: Delivers newly generated Posterizarr artwork immediately so you don't have to wait for scheduled tasks.
  • Plex Direct Sync: Runs on schedule and takes precedence if artwork in Plex differs (e.g. Kometa overlays added in Plex).
